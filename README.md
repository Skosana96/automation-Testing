# 🤖 Automation Testing of Student Management System

This project contains automated test scripts for the **Student Management System**. The goal is to ensure the application’s functionality and stability through systematic testing using automation tools.

---

## 🧪 Testing Overview

- Automated tests cover core features such as student registration, updating records, and deletion.
- Validates user inputs, data integrity, and system responses.
- Includes both **functional** and **regression** tests to maintain system reliability.
